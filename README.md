# 셀프 042 — 아이패드 셀프 포토부스

`booth/`(아이맥 부스 앱)를 복제해서 아이패드 전용으로 다듬은 앱입니다. 두 앱은 서로 의존하지 않습니다.

```
X-S10 ─HDMI─ 캡처카드 ─ 허브(PD 충전) ─ 아이패드 (이 앱) ─와이파이(에어프린트)─ 엡손 P904
                                          └─ 구글 드라이브 ─ 손님 QR · 아이맥
```

## 손님 흐름

**테더 사진(화질, 2026-11-26)**: HDMI 확인 화면은 1620×1080 이라 흐립니다. PC 에서 FUJIFILM **X Acquire** 를 켜고(카메라 PC 연결 모드 "USB 테더 촬영 자동")
저장 폴더(지금 `BOOSPOO`)를 관리자 화면 카메라 칸 **"사진 폴더 고르기"** 로 한 번 고르면, 릴리즈마다 그 폴더에 새로 생긴 카메라 원본 JPG 를 찍은 순서대로
그 컷에 바꿔 넣습니다(긴 쪽 1920 으로 줄여 뷰티·색감·프레임은 그대로, app.js `TETHER`·`tetherPoll`). 화면 미리보기와 셔터 알아채기는 지금처럼 HDMI 입니다.
크롬이 폴더 권한을 물으면 "방문할 때마다 허용". 촬영을 시작할 때 있던 파일은 건너뛰고, 다 찍은 뒤 6초 안에 파일이 안 오면 그 컷은 HDMI 캡처를 씁니다.
HDMI 로 셔터를 못 알아챈 컷이 있으면 뒤 컷이 한 장씩 밀릴 수 있습니다. 앱은 폴더의 사진을 지우지 않습니다. "폴더 안 쓰기"를 누르면 예전처럼 HDMI 만 씁니다.

0. 첫 화면 **어떤 사진을 뽑을까요?** 에서 **포토부스 인화**(엡손 5×7, 아래 1~4)와 **인스탁스 와이드** 중 고릅니다(사용자 요청, 견본 A, 2026-11-26).
   인스탁스를 고르면 **방향을 골라주세요**(가로·세로) → 카메라 → **4장** 찍기 → 고르기 화면에서 **1·2컷**과 사진을 고르고(필름 모양 미리보기, 오른쪽 아래 프린터 상태)

   와이드 프레임 4개(`wl1`·`wl2`·`wp1`·`wp2`, 1260×840)는 `booth/`(photoboo)에 맞춰 둔 값 그대로입니다(설정 version 32 에서 넣음).

   피부를 하얗게 띄워 인스탁스에서 얼굴이 날아가서 바꿨습니다(2026-11-26, version 37). 관리자 "인화 모션 보기"에 인스탁스 가로·세로 버튼이 있습니다.
   인스탁스로 보낼 때만 **사진 칸을 보정 곡선으로 어둡게** 보냅니다(app.js `INSTAX_CURVE`·`instaxTone`). 시험 인화 스캔을 재 보니 프린터가 중간~밝은 쪽을 크게 밝혀
   화면 165 이상이 종이 흰색이 됐습니다(얼굴 211 → 249). 잰 값을 거꾸로 계산한 곡선을 씁니다. 두 번째 시험 인화(70% 세기 + natural)에서 중간 밝기는 화면과 같아졌고 얼굴만 밝아서(239),
   밝은 쪽을 더 눌렀더니(얼굴 211 → 129) 흰 곳이 210 에서 막혀 뭉개져서, 세 장에서 잰 프린터 반응으로 다시 계산했습니다
   (중간 밝기는 화면 그대로, 얼굴 211 → 143 으로 보내 인화 약 220, 흰 곳 255 → 185 로 보내 인화 약 250).

   가로·세로를 고른 뒤 **색을 골라주세요**에서 **원본·흑백**을 고릅니다(레이아웃 `looks`, app.js `COLOR_PICK`, 사용자 요청, version 34).

2. **카메라 켜기**를 누르면 먼저 **뷰티** 화면입니다(카메라를 보면서 왼쪽 막대로 직접 조절, 순서: 프레임 → 색 → 뷰티 → 촬영 → 사진 고르기 → 스티커 및 조정 → 인화).
   **눈 크게 · 중안부 줄이기 · 얼굴 갸름**(구글 MediaPipe 얼굴 찾기 6점으로 얼굴마다 당겨 그림, 처음 한 번 인터넷에서 받음). 피부 매끈 막대는 몸 테두리가 거뭇하게 번져서 뺐습니다(예전엔 사진 전체를 반지름 17 로 흐려 섞어서 배경·옷이 피부 쪽으로 번졌음).
   대신 부스 촬영에는 **피부색인 곳에만** 들어가는 피부 보정(세기 50, 흐림 8, 원본·흑백 모두)을 늘 넣습니다(사용자 요청, app.js `skinW`·`skinOnly`, 검사 `node tests/skin-check.js`).

   100 일 때 눈 14%·중안부 10%·갸름 10%(처음엔 32·24·16% 였는데 과해서 줄임, 갸름은 2026-11-27 7→10%). 미리보기는 얼굴 위치를 천천히 따라가 떨리지 않게 합니다(`smoothFaces`, 검사 `node tests/beauty-check.js`).

   실시간 미리보기와 찍힌 사진에 똑같이 들어가고, 얼굴을 못 찾으면 뷰티 없이 찍힙니다. **촬영 시작**을 누르면 2분 시계와 릴리즈 촬영이 시작됩니다.
   뷰티 화면도 2분이고(오른쪽 위 시계), 2분이 지나면 촬영이 저절로 시작됩니다. 뷰티 화면 아래에는 그만두기 대신 **촬영 시작**이 있습니다(2026-11-27, 사용자 요청).

- 설정 → 연결 설정 → **HDMI 출력 정보 표시 OFF** (찍기 전 화면의 글자를 없앱니다)
- 설정 → 화면 설정 → **화상 표시 1.5초** (찍힌 사진을 1.5초 보여줘야 앱이 담습니다)
- 자동 전원 끄기 OFF
- 관리자 화면 카메라 칸에서 캡처카드("USB3.0 Video" 등)를 고릅니다.

## 릴리즈 촬영 (어떻게 담나)

부스 앱은 셔터를 직접 누르지 않습니다. 손님이 릴리즈를 누르면 후지 화면이 잠깐 **검게** 바뀌고, 이어서 찍힌 사진이
HDMI 로 들어옵니다. 앱은 화면을 64×36 으로 줄여 매 프레임 보고, 검게 된 뒤 장면이 **0.3초** 멈추면 그때를 담습니다
(`waitRelease`, 숫자는 `REL`). 담은 화면은 양옆 검은 띠를 빼고 가운데 3:2 만 씁니다(1920×1080 → 1620×1080). 찍기 전 미리보기도 같은 가운데 3:2 만 보여 줘서 인스탁스 가로처럼 넓은 칸에서 검은 띠가 안 보입니다(`startLive`, 2026-11-28).
- **카메라 셀프타이머 숫자**: 후지 HDMI 화면 왼쪽 위에 노란 시계·숫자(2 → 1 → 0)가 나오는데, 세로 인스탁스는 가운데만 보여서 잘리고 가로 칸은 미리보기가 거울이라 뒤집혀 보입니다. 그 자리(가운데 3:2 기준 가로 5~28%, 세로 15~42%, `REL_TIMER`)에서 노란 픽셀만 골라 카메라 칸 오른쪽 위에 2배로(칸 높이 18% 까지), 뒤집지 않고 띄웁니다(`drawRelTimer`, 모든 프레임, 2026-11-28). 미리보기에만 보이고 사진에는 안 들어갑니다. 자리는 휴대폰 영상으로 잰 대략 값이라 안 잡히면 `REL_TIMER` 를 고칩니다. 그 자리에 노란 옷·물건이 있으면 노란 덩어리가 같이 뜰 수 있습니다.

- 찍기 전 화면은 거울처럼 보이고, 찍힌 사진은 정방향입니다(`previewMirror`).
- 손님이 너무 빨리 연달아 누르면 놓칠 수 있습니다.
- 화질은 HDMI 크기입니다. 5×7 칸(최대 644 × 666)보다 커서 키우지 않습니다.

## 구글 드라이브 QR

`drive/Code.gs` 를 사장님 구글 계정에 한 번 올립니다.

1. https://script.google.com → **새 프로젝트** → `Code.gs` 내용을 통째로 붙여 넣고 저장합니다.
2. 위쪽 함수 고르는 칸에서 `setup` 을 고르고 **실행** → 권한 허용. (`셀프042 QR` · `셀프042 사진` 폴더가 생기고,
   1시간마다 2일 지난 QR 사진을 휴지통으로 옮깁니다)
3. **배포 → 새 배포 → 유형: 웹 앱**. 실행 사용자: **나**, 액세스 권한: **모든 사용자** → 배포.
4. 나온 **웹 앱 URL** 을 `app.js` 의 `DRIVE_URL` 에 넣고 올립니다(아래 "올리기").
5. 아이맥에 **Google Drive** 앱을 깔고 `셀프042 사진` 폴더를 받으면 찍은 사진이 자동으로 아이맥에 들어옵니다.

- `셀프042 QR` 은 링크가 있는 사람은 볼 수 있습니다. 2일 뒤 휴지통으로 가면 링크가 막힙니다.
- QR 은 드라이브 보기 화면이 아니라 사진 원본(`uc?export=view&id=…`)을 바로 엽니다. 손님은 사진을 길게 눌러 사진 앱에 저장합니다
  (보기 화면의 다운로드는 새 창을 열어 두 번 물었습니다, 사용자 시험).
- `셀프042 사진` 에는 손님마다 `261121_143005` 같은 폴더가 하나 생기고, 인화한 프레임과 찍은 원본(`원본_01.jpg` …)이
  같이 들어갑니다. 스티커를 붙였으면 스티커 없는 프레임(`프레임_낙서없음.jpg`, 낙서 화면 때 지은 이름 그대로)도 같이 들어갑니다(`Code.gs` 를 새로 배포하기 전에는 `원본_00.jpg`). 인생네컷은 10장, 흑백 띠·폴라로이드는 8장. 원본에는 찍을 때 들어간 색감이 그대로 있어 흑백을 고르면 흑백입니다.
  원본은 손님 QR 에는 없고 아이맥에만 들어옵니다.
- `셀프042 사진` 의 손님 폴더도 2일 지나면 휴지통으로 옮깁니다(사용자 요청, 2026-11-26, `Code.gs` `cleanup`). 아이맥의 같은 폴더에서도 같이 사라지니,
  남겨 둘 사진은 2일 안에 다른 폴더로 복사합니다. 드라이브 휴지통에서 30일 동안은 되살릴 수 있습니다.
  `Code.gs` 를 고치면 Apps Script 화면에 붙여 넣고 저장합니다(1시간마다 도는 `cleanup` 은 저장한 코드를 씁니다. 새 배포는 필요 없습니다).
- `DRIVE_KEY`(app.js)와 `KEY`(Code.gs)는 같아야 합니다. 앱이 공개 주소라 완전한 잠금은 아닙니다.
