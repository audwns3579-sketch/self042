# 셀프 042 — 아이패드 셀프 포토부스

`booth/`(아이맥 부스 앱)를 복제해서 아이패드 전용으로 다듬은 앱입니다. 두 앱은 서로 의존하지 않습니다.

```
X-S10 ─HDMI─ 캡처카드 ─ 허브(PD 충전) ─ 아이패드 (이 앱) ─와이파이(에어프린트)─ 엡손 P904
                                          └─ 구글 드라이브 ─ 손님 QR · 아이맥
```

## 손님 흐름

1. 첫 화면("프레임 골라주세요.")에서 프레임 카드를 고릅니다: **인생네컷 세로** 또는 **흑백 3컷 띠** (둘 다 5×7 세로). 카드에 실제 인화 모양이 보입니다.
2. **카메라 켜기**를 누르면 바로 손님이 **릴리즈**를 눌러 한 장씩 찍습니다. 인생네컷 **10장**, 흑백 띠 **6장**.
3. 고르기 화면에서 찍은 사진이 왼쪽에 2줄로, 촬영 칸 모양(인생네컷 1:1)으로 보이고(아래로 내려 봅니다), 인생네컷은 **서로 다른 8장**, 흑백 띠는 **3장**을 고릅니다.
4. 결과 화면에서 **인화**: 관리자 화면 "인화 맥 주소"(https://studio042s-iMac.local:8443)가 있으면 맥이 엡손으로 **창 없이 5×7 무테**로 바로 뽑습니다
   (인화 서버 `POST /print-epson?bg=프레임 바탕색`. 맥이 무테 인쇄 영역에 맞춰 늘리는 만큼 사진 둘레에 바탕색 여백을 붙여 보내서 프레임이 종이에 딱 맞습니다). 주소가 없으면 공유 창 → 프린트.
   **QR**(손님 휴대폰으로 받기, 2일), **저장**(공유 창 → 에어드롭 → 아이맥).
   **좌우 반전**(손님 요청): 칸 안의 사진만 좌우로 뒤집어 다시 만듭니다. 프레임 글씨는 그대로이고, QR 도 새로 만들어
   같은 손님 폴더에 넣습니다(원본은 다시 안 올림). 인화를 보낸 뒤에는 누를 수 없습니다(두 장 나가는 것을 막음).

인스탁스는 이 앱에서 쓰지 않습니다.

관리자 화면 맨 위 **화면 디자인**에서 고릅니다(기본 다크 시크). 글씨체는 시안 9가지 중 사용자가 골랐고, 주황색은 쓰지 않습니다.

색은 `index.html` 의 `body[data-theme=…]` 규칙에 있습니다.

## 관리자 화면

맨 위 이름을 길게 누르면 열립니다. 화면 디자인 · 카메라 · 인화 맥 주소 · 보정과 색감 · 인화 방식(켜기, 필름) · 사진 칸 · 글자 · 절취선 · 설정 내보내기/가져오기가 있습니다.
부스 앱(`booth/`)에 있던 인스탁스 실시간 받기, 찍어 둔 사진 불러오기, 고르기 화면 색감 버튼, 카메라 그림, 인화지 크기, 배경·프레임 이미지는
이 앱에서 쓰지 않아 뺐습니다(2026-11-20).

## 프레임

포토샵 `photoshop/액션/` 의 두 스크립트와 같은 숫자입니다. 숫자는 `app.js` 의 `defaultConfig()` 와
`FILM` · `BW_STRIP` 에 있습니다.

| 프레임 | 크기 | 칸 |
|---|---|---|
| 인생네컷 세로 (`인생네컷세로 5x7.jsx`) | 1500 × 2100 | 정사각형 486 × 8칸, 필름 띠 2줄 (띠 폭 750, 칸 사이 30, 위아래 33) |
| 흑백 3컷 띠 (`흑백 3컷 띠 5x7.jsx`) | 1500 × 2100 | 644 × 666 × 3칸 × 2줄, 모서리 16, 띠 #202020 |

포토샵과 다른 점: 필름 띠의 입자(GRAIN)와 흑백 띠의 가장자리 흐림(FADE)은 넣지 않았습니다. 흑백 느낌은 보정
`bwstrip`(대비 110, 밝기 97, 먹색 띄우기 10, 푸른빛 4)으로 비슷하게 맞췄습니다.

## 카메라 (X-S10) 설정

- 다이얼: **사진 모드**
- 설정 → 연결 설정 → **HDMI 출력 정보 표시 OFF** (찍기 전 화면의 글자를 없앱니다)
- 설정 → 화면 설정 → **화상 표시 1.5초** (찍힌 사진을 1.5초 보여줘야 앱이 담습니다)
- 자동 전원 끄기 OFF
- 관리자 화면 카메라 칸에서 캡처카드("USB3.0 Video" 등)를 고릅니다.

## 릴리즈 촬영 (어떻게 담나)

부스 앱은 셔터를 직접 누르지 않습니다. 손님이 릴리즈를 누르면 후지 화면이 잠깐 **검게** 바뀌고, 이어서 찍힌 사진이
HDMI 로 들어옵니다. 앱은 화면을 64×36 으로 줄여 매 프레임 보고, 검게 된 뒤 장면이 **0.3초** 멈추면 그때를 담습니다
(`waitRelease`, 숫자는 `REL`). 담은 화면은 양옆 검은 띠를 빼고 가운데 3:2 만 씁니다(1920×1080 → 1620×1080).

- 찍기 전 화면은 거울처럼 보이고, 찍힌 사진은 정방향입니다(`previewMirror`).
- 손님이 너무 빨리 연달아 누르면 놓칠 수 있습니다.
- 화질은 HDMI 크기입니다. 5×7 칸(최대 644 × 666)보다 커서 키우지 않습니다.

## 구글 드라이브 QR

`drive/Code.gs` 를 사장님 구글 계정에 한 번 올립니다.

1. https://script.google.com → **새 프로젝트** → `Code.gs` 내용을 통째로 붙여 넣고 저장합니다.
2. 위쪽 함수 고르는 칸에서 `setup` 을 고르고 **실행** → 권한 허용. (`셀프042 QR` · `셀프042 사진` 폴더가 생기고,
   1시간마다 2일 지난 QR 사진을 휴지통으로 옮깁니다)
3. **배포 → 새 배포 → 유형: 웹 앱**. 실행 사용자: **나**, 액세스 권한: **모든 사용자** → 배포.
4. 나온 **웹 앱 URL** 을 `app.js` 의 `DRIVE_URL` 에 넣고 올립니다(아래 "올리기").
5. 아이맥에 **Google Drive** 앱을 깔고 `셀프042 사진` 폴더를 받으면 찍은 사진이 자동으로 아이맥에 들어옵니다.

- `셀프042 QR` 은 링크가 있는 사람은 볼 수 있습니다. 2일 뒤 휴지통으로 가면 링크가 막힙니다.
- QR 은 드라이브 보기 화면이 아니라 사진 원본(`uc?export=view&id=…`)을 바로 엽니다. 손님은 사진을 길게 눌러 사진 앱에 저장합니다
  (보기 화면의 다운로드는 새 창을 열어 두 번 물었습니다, 사용자 시험).
- `셀프042 사진` 에는 손님마다 `261121_143005` 같은 폴더가 하나 생기고, 인화한 프레임과 찍은 원본(`원본_01.jpg` …)이
  같이 들어갑니다. 인생네컷은 10장, 흑백 띠는 6장. 원본에는 찍을 때 들어간 색감이 그대로 있어 흑백 띠는 흑백입니다.
  원본은 손님 QR 에는 없고 아이맥에만 들어옵니다.
- `셀프042 사진` 은 지우지 않습니다. 드라이브 용량(무료 15GB)을 가끔 보세요.
- `DRIVE_KEY`(app.js)와 `KEY`(Code.gs)는 같아야 합니다. 앱이 공개 주소라 완전한 잠금은 아닙니다.
