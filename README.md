# 셀프 042 — 아이패드 셀프 포토부스

`booth/`(아이맥 부스 앱)를 복제해서 아이패드 전용으로 다듬은 앱입니다. 두 앱은 서로 의존하지 않습니다.

```
X-S10 ─HDMI─ 캡처카드 ─ 허브(PD 충전) ─ 아이패드 (이 앱) ─와이파이(에어프린트)─ 엡손 P904
                                          └─ 구글 드라이브 ─ 손님 QR · 아이맥
```

## 손님 흐름

1. 첫 화면("프레임 골라주세요.")에서 프레임 카드를 고릅니다: **인생네컷 세로**, **옛날필름 4컷**, **흑백 3컷 띠**, **흑백 3컷 붙임**, **카메라 8컷**, **폴라로이드 9컷** (모두 5×7 세로, 1920 화면에 한 줄).
   옛날필름 4컷은 인생네컷과 같은 필름 띠에서 사진 사이 띠를 없애 위아래로 붙인 판입니다(칸 486×506, 사이 2px 테 선, 서로 다른 8장).
   폴라로이드 9컷은 사용자가 준 9컷 포스터 예시를 글씨·테이프만 빼고 같게 만든 판입니다(`frames/polaroid9.png`: 거의 흰 종이 위 3×3 폴라로이드 카드,
   왼쪽 두꺼운 여백에 "042.s" 음영 각인, 옅은 그림자, 사진 칸 307×486 세로라 가로 사진은 가운데만 들어감, 10장 중 9장).
   흑백 3컷 붙임은 빈티지 포토부스처럼 흑백 사진 3장을 위아래로 붙인 판입니다(검은 테 40, 칸 670×670, 사이 4px 선, 필름 입자·어두운 모서리, 3장 골라 두 줄 반복).
   옛날필름 4컷은 고르기 화면에 **컬러 / 흑백** 버튼이 있어서 손님이 고릅니다(흑백은 흑백 3컷 띠와 같은 보정 `bwstrip`, 프레임에만 입히고 아이맥 원본은 찍은 그대로). 카드에 실제 인화 모양이 보입니다.
   보정 아래 **프레임 색을 골라주세요**에서 바탕색을 고릅니다(색 동그라미 + 작은 미리보기, app.js `FRAME_COLORS`). 첫 번째가 예전부터 쓰던 색이라 안 누르면 그대로입니다.
   인생네컷·옛날필름 4컷: 블랙·화이트(필름 구멍·글씨·절취선 색도 같이 바뀜, 흰색은 긁힘 효과 없음) / 흑백 3컷: 블랙·화이트 / 카메라 8컷: 블루 체커·핑크 체커.
   (처음엔 프레임마다 5가지였다가 사용자 요청으로 2가지씩만 남겼습니다.) 고른 색은 고르기 미리보기·인화·QR·아이맥 보관에 다 들어가고, 엡손 바깥 여백도 그 색으로 붙입니다.
   다음 손님(처음 화면으로 돌아오면)이나 프레임을 다시 고르면 첫 번째 색으로 돌아갑니다.
2. **카메라 켜기**를 누르면 바로 손님이 **릴리즈**를 눌러 한 장씩 찍습니다. 인생네컷·옛날필름·카메라 8컷·폴라로이드 9컷 **10장**, 흑백 띠·흑백 붙임 **6장**.
   카메라 칸 왼쪽에 "릴리즈를 눌러 주세요"와 장 수, 오른쪽에 **남은 시간 3분**이 보입니다. 3분이 끝나면 고를 만큼(8장·3장) 찍었으면
   찍은 사진으로 고르기 화면에 가고, 모자라면 "시간이 끝났습니다" 안내와 함께 처음 화면으로 돌아갑니다.
3. 고르기 화면에서 찍은 사진이 왼쪽에 2줄로, 촬영 칸 모양(인생네컷 1:1)으로 보이고(아래로 내려 봅니다), 인생네컷은 **서로 다른 8장**, 흑백 띠는 **3장**을 고릅니다.
   **이 사진으로 완성** → **스티커 화면**: 탭(**기본·크롬·글자·테이프**)에서 스티커를 누르면 사진 가운데에 붙고,
   손가락으로 끌어 옮깁니다. 고른 스티커 모서리의 손잡이(지름 48px, 스티커와 같이 돎)로 **✕ 빼기 · ↻ 끌어서 돌리기 · ⤡ 끌어서 크기**를 바꿉니다
   (예전 크게·작게·돌리기·빼기 버튼 줄은 다음 버튼 바로 위라 다음이 잘못 눌려서 뺐습니다). 제한 시간 **3분**.
   - 기본 8종(하트·별·반짝이·웃는 얼굴·왕관·꽃·LOVE·042)은 직접 그린 SVG 입니다.
   - 크롬 20·글자 26(대문자)·테이프 59 는 사용자가 핀터레스트에서 받은 이미지를 오려 낸 투명 PNG(`stickers/`, 목록은 app.js `STICKER_FILES`)입니다.
     원본이 작아 크게 붙이면 인화에서 흐릴 수 있습니다. 원작자가 따로 있는 그림이고, 저장소가 공개라 이 파일들도 누구나 받을 수 있습니다.
     워터마크가 걸친 파란 카메라와 기획사 말풍선 시트는 넣지 않았습니다. 분홍 문구 시트·소문자 알파벳은 넣었다가 뺐습니다(사용자 요청).
   - **카메라 8컷** 프레임: 같은 핀터레스트 카메라 이미지 7종(검정은 두 번)을 2줄×4칸으로 놓은 프레임 그림 `frames/camera8.png`(바탕이 투명한 카메라 그림. 바탕은 앱이 손님이 고른 색으로 그림: 체커는 한 칸 75px + 반짝이 40개, `drawCamBack`).
     칸은 카메라 화면 구멍 자리(299×236 ~ 408×316, 구멍 둘레 흰 띠까지 뚫고 키울 때 흰색이 번지지 않게 만듦)이고, 사진을 칸에 넣은 뒤 프레임 그림을 위에 덮습니다(app.js `frameSrc`·`frameImage`).
     카메라 그림은 약 2배 키운 것이라 테두리가 조금 흐릴 수 있습니다. 
   **다음**을 누르거나 3분이 끝나면 스티커를 1500×2100 인화 사진에 같은 자리·크기로 붙여 결과 화면으로 갑니다. 스티커가 없으면 그대로 갑니다.
4. 결과 화면에서 **인화**: 관리자 화면 "인화 맥 주소"(https://studio042s-iMac.local:8443)가 있으면 맥이 엡손으로 **창 없이 5×7 무테**로 바로 뽑습니다
   (인화 서버 `POST /print-epson?bg=프레임 바탕색`. 맥이 무테 인쇄 영역에 맞춰 늘리는 만큼 사진 둘레에 바탕색 여백을 붙여 보내서 프레임이 종이에 딱 맞습니다). 주소가 없으면 공유 창 → 프린트.
   **QR**(손님 휴대폰으로 받기, 2일), **저장**(공유 창 → 에어드롭 → 아이맥).
   **좌우 반전**(손님 요청): 칸 안의 사진만 좌우로 뒤집어 다시 만듭니다. 프레임 글씨와 스티커는 그대로이고, QR 도 새로 만들어
   같은 손님 폴더에 넣습니다(원본은 다시 안 올림). 인화를 보낸 뒤에는 누를 수 없습니다(두 장 나가는 것을 막음).

인스탁스는 이 앱에서 쓰지 않습니다.

## 프레임

포토샵 `photoshop/액션/` 의 두 스크립트와 같은 숫자입니다. 숫자는 `app.js` 의 `defaultConfig()` 와
`FILM` · `BW_STRIP` 에 있습니다.

| 프레임 | 크기 | 칸 |
|---|---|---|
| 인생네컷 세로 (`인생네컷세로 5x7.jsx`) | 1500 × 2100 | 정사각형 486 × 8칸, 필름 띠 2줄 (띠 폭 750, 칸 사이 30, 위아래 33) |
| 흑백 3컷 띠 (`흑백 3컷 띠 5x7.jsx`) | 1500 × 2100 | 644 × 666 × 3칸 × 2줄, 모서리 16, 띠 #202020 |

포토샵과 다른 점: 필름 띠의 입자(GRAIN)와 흑백 띠의 가장자리 흐림(FADE)은 넣지 않았습니다. 흑백 느낌은 보정
`bwstrip`(대비 110, 밝기 97, 먹색 띄우기 10, 푸른빛 4)으로 비슷하게 맞췄습니다.

## 카메라 (X-S10) 설정

- 다이얼: **사진 모드**
- 설정 → 연결 설정 → **HDMI 출력 정보 표시 OFF** (찍기 전 화면의 글자를 없앱니다)
- 설정 → 화면 설정 → **화상 표시 1.5초** (찍힌 사진을 1.5초 보여줘야 앱이 담습니다)
- 자동 전원 끄기 OFF
- 관리자 화면 카메라 칸에서 캡처카드("USB3.0 Video" 등)를 고릅니다.

## 릴리즈 촬영 (어떻게 담나)

부스 앱은 셔터를 직접 누르지 않습니다. 손님이 릴리즈를 누르면 후지 화면이 잠깐 **검게** 바뀌고, 이어서 찍힌 사진이
HDMI 로 들어옵니다. 앱은 화면을 64×36 으로 줄여 매 프레임 보고, 검게 된 뒤 장면이 **0.3초** 멈추면 그때를 담습니다
(`waitRelease`, 숫자는 `REL`). 담은 화면은 양옆 검은 띠를 빼고 가운데 3:2 만 씁니다(1920×1080 → 1620×1080).

- 찍기 전 화면은 거울처럼 보이고, 찍힌 사진은 정방향입니다(`previewMirror`).
- 손님이 너무 빨리 연달아 누르면 놓칠 수 있습니다.
- 화질은 HDMI 크기입니다. 5×7 칸(최대 644 × 666)보다 커서 키우지 않습니다.

## 구글 드라이브 QR

`drive/Code.gs` 를 사장님 구글 계정에 한 번 올립니다.

1. https://script.google.com → **새 프로젝트** → `Code.gs` 내용을 통째로 붙여 넣고 저장합니다.
2. 위쪽 함수 고르는 칸에서 `setup` 을 고르고 **실행** → 권한 허용. (`셀프042 QR` · `셀프042 사진` 폴더가 생기고,
   1시간마다 2일 지난 QR 사진을 휴지통으로 옮깁니다)
3. **배포 → 새 배포 → 유형: 웹 앱**. 실행 사용자: **나**, 액세스 권한: **모든 사용자** → 배포.
4. 나온 **웹 앱 URL** 을 `app.js` 의 `DRIVE_URL` 에 넣고 올립니다(아래 "올리기").
5. 아이맥에 **Google Drive** 앱을 깔고 `셀프042 사진` 폴더를 받으면 찍은 사진이 자동으로 아이맥에 들어옵니다.

- `셀프042 QR` 은 링크가 있는 사람은 볼 수 있습니다. 2일 뒤 휴지통으로 가면 링크가 막힙니다.
- QR 은 드라이브 보기 화면이 아니라 사진 원본(`uc?export=view&id=…`)을 바로 엽니다. 손님은 사진을 길게 눌러 사진 앱에 저장합니다
  (보기 화면의 다운로드는 새 창을 열어 두 번 물었습니다, 사용자 시험).
- `셀프042 사진` 에는 손님마다 `261121_143005` 같은 폴더가 하나 생기고, 인화한 프레임과 찍은 원본(`원본_01.jpg` …)이
  같이 들어갑니다. 스티커를 붙였으면 스티커 없는 프레임(`프레임_낙서없음.jpg`, 낙서 화면 때 지은 이름 그대로)도 같이 들어갑니다(`Code.gs` 를 새로 배포하기 전에는 `원본_00.jpg`). 인생네컷은 10장, 흑백 띠는 6장. 원본에는 찍을 때 들어간 색감이 그대로 있어 흑백 띠는 흑백입니다.
  원본은 손님 QR 에는 없고 아이맥에만 들어옵니다.
- `셀프042 사진` 은 지우지 않습니다. 드라이브 용량(무료 15GB)을 가끔 보세요.
- `DRIVE_KEY`(app.js)와 `KEY`(Code.gs)는 같아야 합니다. 앱이 공개 주소라 완전한 잠금은 아닙니다.
